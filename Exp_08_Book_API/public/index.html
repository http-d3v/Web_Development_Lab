API Endpoint Reference

Method Endpoint Description Parameters / Body Success
GET /api/books Retrieve all library books with optional query filtering ?genre=, ?author=, ?search= 200 OK
GET /api/books/:id Retrieve details of a single book by integer ID id (URL param) 200 OK
POST /api/books Add a new book (validates title & author presence) JSON: title, author, genre, year, isbn 201 Created
PUT /api/books/:id Update fields of an existing book id (param) + JSON body of updated fields 200 OK
DELETE /api/books/:id Remove a book by integer ID from the collection id (URL param) 200 OK

cURL & Testing Snippets

1. Fetch All Books 
curl -X GET http://localhost:3000/api/books
2. Create Book (POST) 
curl -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d '{"title":"Deep Learning","author":"Ian Goodfellow","genre":"AI","year":2016}'
3. Update Book (PUT) 
curl -X PUT http://localhost:3000/api/books/1 \
  -H "Content-Type: application/json" \
  -d '{"available":false}'
4. Delete Book (DELETE) 
curl -X DELETE http://localhost:3000/api/books/4
