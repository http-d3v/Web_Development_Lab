# Web Development Laboratory (B.Tech CSE)

Welcome to the comprehensive laboratory repository for **Web Development Laboratory** (Experiments 02 – 12), created by **Dev Kumar Tiwari** ([@http-d3v](https://github.com/http-d3v)).

## 🎨 Design Philosophy
- **Natural, Professional Student Craft:** Clean hierarchy, thoughtful typography (`Plus Jakarta Sans`), generous breathing room, natural spacing.
- **Warm Editorial Color Palette:**
  - Base Background: `#FDFBF7`
  - Surface Background: `#F4EFE6`
  - Charcoal Typography: `#2C2522`
  - Terracotta Accent: `#A25E3E`
  - Forest Olive: `#48604F`
- **Zero AI-Gimmicks:** No oversized fonts, no distracting neon glow, no glassmorphism or useless animation clutter.
- **Clean & Academic Ready:** Clean code comments, logical file separation, full `README.md` per experiment.
