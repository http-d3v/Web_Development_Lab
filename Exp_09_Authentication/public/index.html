Authentication Workflow & Principles

01

Password Hashing

Passwords are never stored in plaintext. They undergo 10 salt rounds with bcryptjs, rendering them resistant to rainbow table lookups.

02

Stateless JWTs

Authentication tokens are cryptographically signed using HMAC-SHA256 with a private server secret, eliminating the need for server-side sessions.

03

Bearer Auth Middleware

Protected endpoints inspect the Authorization request header. Invalid, modified, or expired tokens receive an immediate 401 Unauthorized response.
